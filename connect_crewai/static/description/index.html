Connect CrewAI

Multi-Agent AI Orchestration for Odoo

Overview

Connect CrewAI integrates the powerful CrewAI framework into Odoo, enabling you to build, manage, and execute multi-agent AI workflows directly from your Odoo interface. Create teams of AI agents that collaborate to solve complex tasks, automate research, generate content, and much more.

Key Features

  • AI Agent Management - Create and configure AI agents with specific roles, goals, and backstories
  • Task Definition - Define clear tasks with descriptions and expected outputs
  • Crew Orchestration - Organize agents into crews for collaborative work
  • Multiple Process Types - Sequential or hierarchical task execution
  • Multiple LLM Support - OpenAI, Anthropic Claude, Google Gemini, and local Ollama
  • Tool Integration - Web search, file operations, code interpretation, and more
  • Execution Tracking - Monitor crew executions, view results, and track token usage
  • Memory & Cache - Enable agents to remember past interactions

Installation

Step 1: Install Python Dependencies

pip install crewai crewai-tools langchain-openai langchain-anthropic langchain-google-genai langchain-community

Step 2: Install the Module

  1. Update the Apps List in Odoo
  2. Search for "Connect CrewAI"
  3. Click Install

Configuration

API Keys Setup

Configure your LLM provider API keys in Connect Settings:

  • OpenAI: Set the openai_api_key parameter
  • Anthropic: Set the anthropic_api_key parameter
  • Google: Set the google_api_key parameter
  • Ollama: No API key needed (local installation)
Note: At least one LLM provider must be configured for the module to work properly.

Quick Start Guide

1. Create Agents

Navigate to Connect → CrewAI → Agents and create your first agent:

  • Name: Senior Research Analyst
  • Role: Research Expert
  • Goal: Find and analyze relevant information on given topics
  • Backstory: You are an experienced researcher with expertise in data gathering and analysis
  • LLM Provider: OpenAI
  • LLM Model: gpt-4o
  • Tools: search_tool

2. Define Tasks

Go to Connect → CrewAI → Tasks and create tasks:

  • Name: Research Topic
  • Description: Research the given topic and gather relevant information
  • Expected Output: A comprehensive research report with key findings
  • Agent: Senior Research Analyst

3. Build a Crew

Navigate to Connect → CrewAI → Crews and create a crew:

  • Name: Research Team
  • Description: Team dedicated to research and analysis
  • Agents: Add your agents
  • Tasks: Add your tasks
  • Process: Sequential

4. Execute the Crew

Open your crew and click Execute Crew. Optionally provide inputs as JSON:

{
    "topic": "Artificial Intelligence in Healthcare",
    "focus_areas": ["diagnostics", "treatment", "patient care"]
}

Process Types

Sequential Process

Tasks are executed one after another in the order specified by their sequence number. Each task's output can be used as input for subsequent tasks. This is ideal for linear workflows where each step depends on the previous one.

Hierarchical Process

A manager agent (automatically created) coordinates task delegation and execution. The manager decides which agents work on which tasks and ensures optimal collaboration. This is ideal for complex workflows requiring intelligent task distribution.

Note: Hierarchical process requires specifying a Manager LLM model (e.g., gpt-4o, claude-3-5-sonnet-20241022).

Advanced Features

Memory

Enable memory for crews to allow agents to remember and learn from past interactions. This improves performance over time and enables more contextual responses.

Async Execution

Mark tasks as async to run them in parallel when possible, significantly speeding up crew execution.

Custom Context

Provide additional context to tasks to guide agent behavior and improve output quality.

Output Files

Specify output file paths for tasks to automatically save results to the filesystem.

Best Practices

  • Clear Roles: Define specific, focused roles for each agent
  • Detailed Goals: Provide clear, measurable goals for agents
  • Rich Backstories: Give agents context to improve their understanding
  • Precise Task Descriptions: Clearly describe what each task should accomplish
  • Define Expected Outputs: Specify exactly what format and content you expect
  • Start Simple: Begin with sequential processes before moving to hierarchical
  • Monitor Token Usage: Keep track of token consumption to manage costs
  • Test Iteratively: Refine agent configurations based on execution results

Troubleshooting

API Key Errors

Ensure your API keys are correctly configured in Connect Settings.

Tool Import Errors

Install the crewai-tools package and its dependencies.

LangChain Errors

Verify all LangChain packages are installed: langchain-openai, langchain-anthropic, etc.

Execution Timeouts

Increase the max_execution_time for agents or adjust task complexity.
