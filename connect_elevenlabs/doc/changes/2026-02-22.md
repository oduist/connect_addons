### Added

- **Agent templates**: a reusable system prompt an agent can be created from,
  so a working agent no longer starts with an empty prompt.
- **Agent transfers** as configuration rather than prompt text. An agent can
  hand the conversation to another agent -- a general one passing to a
  specialist -- or to a person, where the call arrives at an extension and rings
  normally.

### Changed

- The tool endpoints check the ElevenLabs agent token and refuse anything else.
  The refusal arrives as a jsonrpc error envelope inside a `200`, not as an
  HTTP `401`.
- Numbers synchronise more reliably between Odoo and the provider.
