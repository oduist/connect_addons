### Added

- The module, giving voice AI agents documents to answer from. A knowledge
  library where a document is a URL, an uploaded file or text typed in directly;
  the draft/creating/active/error lifecycle with a retry; attaching documents to
  agents from either side; and a **Knowledge Base** tab on the agent form.
- Markdown (`.md`) accepted alongside `.epub`, `.pdf`, `.docx`, `.txt` and
  `.html`.
