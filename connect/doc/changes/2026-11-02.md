### Added

- `doc/tech_spec.md`, sections *Settings fields*, *Methods on
  `connect.settings`* and *Settings form*: the `whisper_prompt` field
  ("Whisper Prompt"), sent as `prompt` to the Whisper server when non-empty,
  and its "Prompt" field on the Transcription tab.

### Changed

- `doc/admin_guide.md`, section *Transcription*: the **Prompt** row now
  covers both self-hosted engines and explains the difference — Nemotron
  follows an instruction, Whisper reads the prompt as text said before the
  call, so it takes the names spelled as they should appear.

- `doc/admin_guide.md`, section *Transcription*, **Prompt** row: a warning to
  test the Whisper prompt first — a vLLM Whisper server was found to use it
  as the start of the transcript, skipping matching speech ("Mirage Pools."
  dropped those words from the greeting; a longer prompt dropped 26–63 % of
  the words of two calls).
