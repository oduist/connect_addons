### Added

- `doc/tech_spec.md`, sections *Settings fields*, *Methods on
  `connect.settings`* and *Settings form*: the `whisper_prompt` field
  ("Whisper Prompt"), sent as `prompt` to the Whisper server when non-empty,
  and its "Prompt" field on the Transcription tab.

- `doc/tech_spec.md`, section *Methods on `connect.settings`*, Nemotron
  constants: `NEMOTRON_TOO_LONG`, the server refusals that
  `_nemotron_chunk()` turns into the "too long" error — the 1,800 s duration
  limit and the 256 MiB decoded-PCM guard, besides the old encoder cache.

### Changed

- `doc/admin_guide.md`, section *Transcription*: the **Prompt** row now
  covers both self-hosted engines and explains the difference — Nemotron
  follows an instruction, Whisper reads the prompt as text said before the
  call, so it takes the names spelled as they should appear.

- `doc/admin_guide.md`, section *Transcription*, **Prompt** row: a warning to
  test the Whisper prompt first — a vLLM Whisper server was found to use it
  as the start of the transcript, skipping matching speech ("Mirage Pools."
  dropped those words from the greeting; a longer prompt dropped 26–63 % of
  the words of two calls).

- `doc/tech_spec.md`, section *Methods on
  `connect.settings`*: Nemotron now sends 20-minute chunks
  (`NEMOTRON_CHUNK_SECONDS` 240 → 1200), since the server takes 30 minutes
  per request instead of ~5.4; `NEMOTRON_MAX_TOKENS` 2048 → 8192,
  and `NEMOTRON_HTTP_TIMEOUT` 600 → 1200. The constants are now a list, each
  with the server limit it is sized against; `NEMOTRON_DEFAULT_PROMPT` is
  unchanged and says why it is not NVIDIA's verbatim instruction.

- `doc/admin_guide.md`, section *Transcription*: the **Prompt** row warns
  against asking Nemotron for a "verbatim" transcript (backchannels, spelled
  names, speaker tags). The **Self-hosted Nemotron** item under *Limits
  worth knowing*: 20-minute pieces, so most calls go in one request and have
  one timestamp; the new defaults; and why the piece length must stay under
  ~25 minutes for Twilio's stereo recordings.
