Yealink T34W phonebook settings

How to connect a Yealink phone to the Odoo remote phonebook and what the related phone options do. All settings below are in the phone's web interface (browse to the phone's IP address and log in as admin).

Point the phone at Odoo

  • Open Directory → Remote Phone Book.
  • In row 1, paste the Phonebook URL from Odoo (Settings → Phonebook) into Remote URL and set a Display Name such as Odoo Contacts.
  • Set Incoming/Outgoing Call Lookup to Enabled — this is the caller-ID feature and the main payoff of the integration:
    • Enabled: when a call comes in (or you dial out), the phone searches the remote phone book for the number and, on a match, shows the contact's name on the display and in the call history instead of the bare number.
    • Disabled: the remote phone book is still browsable and diallable under Menu → Directory → Remote Phone Book, but calls display only the raw caller ID — the phone won't consult the remote book to name them.
  • Set Update Time Interval to 3600 so the phone silently re-downloads the directory every hour. The phone matches calls against its local copy — a contact added in Odoo appears after the next refresh (opening the directory on the handset forces one immediately).

Directory → Settings

  • Directory (top list) controls which phonebooks appear when you press the Directory key / Menu → Directory on the handset. Remote Phone Book must be in the Enabled column there for staff to browse and search the Odoo directory at all.
  • Search Source List In Dialing (bottom list) controls predictive search while dialing: when someone lifts the handset and starts typing digits or letters on the pre-dialing screen, the phone live-matches the input against the enabled sources and shows matching contacts as pick-and-call suggestions. Moving Remote Phone Book to Enabled means typing MASN… or the first digits of a number will surface the matching Odoo customer before you finish dialing. Keep Local Directory and History above it so the most likely matches appear first; if the dialing screen ever feels sluggish, move Remote Phone Book back out of this list (browsing and caller-ID lookup are unaffected).
The phone never contacts Odoo during a call: caller-ID lookup and dial-time search both run against the phone's cached copy of the phonebook, downloaded when the directory is opened and at the Update Time Interval.
