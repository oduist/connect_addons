### Added

- The module, teaching the voice AI agent to work with Helpdesk. Five
  token-protected endpoints and the tools in front of them: create a ticket,
  search a caller's tickets, fetch one, update it, and add a note. A
  *Helpdesk Support Agent* template ships with a working prompt, and a ticket
  the agent opens links the call it came from, so the recording, transcript and
  summary travel with it.
