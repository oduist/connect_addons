### Added

- `user_guide.md`: first end-user guide — what the agent can do with the
  catalogue and orders, how to check agent-created orders against the
  transcript, what the agent reports about stock, and the
  published-products-only rule.
- `admin_guide.md`: first administrator guide — the five shipped tools and their
  token-protected endpoints, the published-only catalogue, the setup sequence
  including SYNC TOOLS, guidance on whether to let the agent create partners and
  orders, and a health check.

### Changed

- `user_guide.md` and `admin_guide.md`, stock sections: `get_products` now
  returns the real on-hand quantity instead of the hardcoded `10` it used to
  report for every product. Documented the three cases the agent must
  distinguish (a number, zero, not tracked) and the two caveats: the figure is
  on-hand rather than free-to-promise, and it is a snapshot taken during the
  call.

```diff
-'items_in_stock': 10,
+'items_in_stock': self._items_in_stock(k),
```

- The `get_products` tool description now tells the agent what `items_in_stock`
  means and forbids stating an availability when it is null.
