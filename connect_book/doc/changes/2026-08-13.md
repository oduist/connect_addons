### Added

- `user_guide.md`: initial guide -- opening the books, searching, the Changes
  archive, why a module may have no page.
- `admin_guide.md`: initial guide -- who may read the Admin Guide, where doc
  files live, which modules are crawled, render limits and caching.
- `tech_spec.md`: initial module SPEC for `connect.book`, the three jsonrpc
  endpoints and the three client actions.

### Changed

- `models/markdown.py`: fixed a list-rendering defect where a list item that
  switched kind (unordered <-> ordered) at the same indentation, with no blank
  line separating it from the previous item, silently dropped that item and
  every item after it from the rendered HTML. `_consume_list` now renders the
  collected items as successive `<ul>`/`<ol>` runs, resuming from wherever the
  previous run stopped, instead of discarding the renderer's stop position.
  `tech_spec.md`'s list-rendering rules are updated to describe the new
  behavior.
- `models/connect_book.py`: `get_book()` and `get_changes()` now require the
  caller to hold `connect.group_connect_user` or `connect.group_connect_admin`,
  raising `AccessError` otherwise -- the same shape `get_admin_book()` already
  used for its own, narrower requirement. Previously these two routes were
  reachable by any authenticated user, portal included, once the menu gate was
  bypassed by calling `/connect_book/book` or `/connect_book/changes` directly.
  `admin_guide.md` and `tech_spec.md` are updated to describe the new
  server-side gate and to correct the now-false "route-level access is wider
  than menu-level access" statement.
